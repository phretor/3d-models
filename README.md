# 3d-models

Personal collection of 3D-printable models, mostly designed in FreeCAD.

## Contents

- `100W Slim LED PSU case/` — enclosure for a slim 100W LED power supply
- `Adattatore Condensa Daikin/` — condensate drain adapter for a Daikin unit
- `Aletta Doccia/` — shower fin/guard
- `Aletta Porta/` — door fin/guard
- `Disc/` — small disc part
- `Supporto Catenaccio/` — bolt/latch support
- `Tactile switch box/` — enclosure for a tactile switch
- `webcam-mount/` — webcam mount

Each folder typically contains a FreeCAD source (`.FCStd`) and exported `.stl` / `.3mf` files for slicing.
